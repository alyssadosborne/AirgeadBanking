# Airgead Banking Investment Calculator

A C++ console application designed to help users understand how investments grow over time through compound interest.

The application allows users to enter their initial investment amount, monthly deposit, annual interest rate, and investment duration. It then calculates and displays projected investment growth under two scenarios: with and without additional monthly deposits.

**Features:**

Investment Calculations: Calculate projected investment growth using compound interest.

Customizable Inputs: Enter an initial deposit, monthly contributions, annual interest rate, and investment duration.

Scenario Comparison: Compare investment growth with and without recurring monthly deposits.

Yearly Reports: Display annual balances and earned interest.

Organized Output: Present financial calculations in a readable, structured format.

**How It Works:**

The program accepts four primary inputs:

Initial investment amount

Monthly deposit amount

Annual interest rate

Number of investment years

Using these values, the application calculates investment growth and generates annual summaries.

The program compares results with and without monthly contributions, allowing users to understand how recurring deposits influence long-term savings.

**Programming Concepts Demonstrated:**

Modular Programming: Separate functions organize calculations and output.

Mathematical Logic: Compound interest calculations are applied to user-provided financial information.

Iteration: Loops process investment growth over multiple periods.

User Interaction: Console input allows users to customize the calculations.

Formatted Output: Results are organized into readable financial reports.

Debugging: Different input values were tested to identify and resolve calculation issues.

**Challenges and Solutions:**

One of the primary challenges was implementing accurate interest calculations while presenting the results in an understandable format.

I addressed these challenges by reviewing course materials, testing different financial scenarios, and using debugging tools to identify and correct errors.

Organizing the program into separate functions also made the code easier to understand and maintain.
