# AirgeadBanking
An application that allows users to see how their investments will grow over time.

The Airgead Banking project is a C++ program that shows users how their investments can grow over time. It calculates the compound interest based on the initial investment, monthly deposits, annual interest rate, and number of years. The program then displays the yearly balances and earned interest, both with and without the extra monthly deposits. I was able to create clear and organized calculations, and I broke down the program into separate functions, each with its own specific job. This made it easier to manage and understand the code. However, the hardest part was getting the interest calculations just right and formatting the results in a way that made sense. To overcome these challenges, I went back to the course materials, tried out different values, and used debugging tools to find and fix the problems. By doing this, I was able to get the program working correctly and producing accurate results. The program is designed to be user-friendly, accepting input from the user and displaying the results in a clear and easy-to-understand format. Overall, the Airgead Banking project was a great learning experience, and I'm proud of what I was able to accomplish.

I could improve the program by adding stronger input validation and clearer error messages for invalid or negative values. These improvements would make it more secure and user-friendly. Skills from this project that will transfer to future coursework include writing functions, using loops, performing calculations, formatting output, validating input, and testing code. I made the program maintainable, readable, and adaptable by using descriptive names, comments, consistent formatting, and separate functions for the program’s calculations and displays.
